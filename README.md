# DSA Class Documentation

## Project Topic: Data Analysis And Visualization
This is where I built my first portfolio while learning at the incubator Hub

### Project Overview:
This project covers a Microsoft Power BI course on an online learning portal, with  modules for data and business intelligence professionals. The curriculum teaches four areas: preparing data, modeling data, visualizing and analyzing it, and managing and securing Power BI. Its hands-on exercises require Power BI Desktop and access to the online Power BI service, which offers limited labs

The class will likely cover how to turn raw data into interactive reports

### Data Source:
The main data source is where we make use of Power BI reports to get data stored in Excel workbooks, CSVs, and text files.
The power bi desktop app can be downloaded from Microsoft web.

### Tools Used

- Excel: a common data source to import from [Click here to download](https://www.microsoft.com)
- Power Query: the data-cleaning tool inside Desktop.
- DAX: the formula language used inside Desktop for calculations.
- Power BI Service: the online platform where we publish and share reports.
- Files: Excel workbooks, CSVs, and text files.
- Databases: SQL Server.
   - Ms Power point for presentation
